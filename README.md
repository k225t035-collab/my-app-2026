# Quest Master - Fantasy RPG Edition

タスク管理を「冒険（クエスト）」へと変貌させる、RPG要素を搭載したタスク管理アプリです。

---

## ゲームシステム

### 1. クエスト（タスク）の受注と遂行
- **クエスト受注**: 入力欄に内容を書き、難易度を選択して「受注」します。
- **難易度と報酬**:
  - **初級 (Low)**: 10 XP / 5 Gold
  - **中級 (Medium)**: 20 XP / 15 Gold
  - **上級 (High)**: 50 XP / 40 Gold
- **完遂**: チェックボックスをオンにすると、報酬（XPとゴールド）を獲得できます。**一度完遂したクエストは元に戻すことはできません（冒険の成果が固定されます）。**

### 2. 成長システム
- **経験値 (XP)**: クエストを完遂すると獲得。ゲージが満タンになるとレベルアップ！
- **レベル**: あなたの冒険者としての熟練度を表します。
- **ゴールド**: 完遂した証として蓄積されます。
- **レベルアップ演出**: レベルが上がるとド派手なメッセージが表示されます。

### 3. 視覚・聴覚効果
- **中世ファンタジーUI**: 羊皮紙と木目をイメージした重厚なデザイン。
- **ダイナミックサウンド**: 
  - クエスト受注（剣の音）
  - クエスト完遂（ファンファーレ）
  - レベルアップ（豪華な祝福音）
  - 背景音楽（BGMのオン/オフ切り替え可能）
- **振動エフェクト**: クエスト受注時に画面が揺れるフィードバック。
- **ホバーアクション**: クエストにカーソルを合わせると金色に輝きます。

## 技術仕様
- **テーマ**: ダークファンタジー / RPG
- **フォント**: Cinzel, MedievalSharp (Google Fonts)
- **データ保存**: `localStorage`（レベル、経験値、ゴールド、タスクの状態をすべて保存）
- **レスポンシブ**: モバイルデバイスでも冒険を楽しめます。

## 開発と公開

### 公開方法
1. GitHub Pages を有効化してください。
2. ソースとして `main` ブランチの `/ (root)` を指定します。

### ローカルでの実行
`index.html` をブラウザで開くだけで、すぐに冒険を始められます。
