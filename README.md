## ユーザーマニュアル

### 1. 基本機能の使い方

#### タスクを追加する
1. 画面上部の「新しいタスクを入力...」と書かれた入力欄にタスク名を入力します。
2. 右側のプルダウンメニューから優先度（低・中・高）を選択します。
3. 「追加」ボタンをクリックするか、Enterキーを押すとタスクがリストに追加されます。

#### タスクを完了にする
- 各タスクの左側にあるチェックボックスをクリックします。
- 完了したタスクは打ち消し線が表示され、文字が薄くなります。

#### タスクを削除する
- タスクの右側にある「×」ボタンをクリックすると、そのタスクが削除されます。

### 2. 便利な機能

#### 優先度の色分け
タスクの左端には、優先度に応じた色が表示されます。
- **赤**: 高 (High)
- **オレンジ**: 中 (Medium)
- **緑**: 低 (Low)

#### 表示の絞り込み（フィルタ）
リスト上部のボタンを使って、表示するタスクを切り替えられます。
- **すべて**: 全てのタスクを表示します。
- **未完了**: まだ終わっていないタスクのみ表示します。
- **完了済み**: 終わったタスクのみ表示します。

### 3. データの保存について
このアプリはブラウザの **LocalStorage** 機能を使用しています。
- ブラウザを閉じたり、ページを再読み込みしたりしても、タスクの内容は保存されたままになります。
- ※ブラウザのキャッシュをクリアしたり、別のブラウザで開いた場合はデータが引き継がれません。

## 技術仕様

### 特徴
- **モダン・ダークテーマ**: ネオンアクセントのスタイリッシュなUI。
- **優先度設定**: 3段階の色分け管理。
- **レスポンシブ**: スマートフォン対応。

### 技術スタック
- HTML5 / CSS3 / JavaScript (Vanilla JS)

## 開発と公開

1. GitHub Pages を有効化し、`main` ブランチをソースとして選択してください。
2. 詳細は GitHub の `Settings > Pages` を参照してください。

### ローカルでの実行
