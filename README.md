# Task Master

モダンでダークなデザインのタスク管理アプリです。

## 特徴
- **モダン・ダークテーマ**: ネオンアクセントのスタイリッシュなUI。
- **優先度設定**: 高・中・低の3段階でタスクを色分け管理。
- **フィルタ機能**: 全て、未完了、完了済みでタスクを絞り込み。
- **データ永続化**: ブラウザの `localStorage` を使用してタスクを保存。
- **レスポンシブ**: スマートフォンでも快適に利用可能。

## 技術スタック
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)

## GitHub Pages への公開方法

1. **GitHub リポジトリの作成**:
   - GitHubで新しいリポジトリを作成します。
   - このコードをリポジトリにプッシュします。

2. **GitHub Pages の有効化**:
   - リポジトリの `Settings` タブをクリックします。
   - 左サイドバーの `Pages` をクリックします。
   - `Build and deployment` セクションの `Source` で `Deploy from a branch` を選択します。
   - `Branch` で `main` (または `master`) ブランチを選択し、`/ (root)` フォルダを選択して `Save` をクリックします。

3. **公開の確認**:
   - 数分待つと、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。

## 開発
ローカルで動作を確認するには、`index.html` をブラウザで開くだけでOKです。
